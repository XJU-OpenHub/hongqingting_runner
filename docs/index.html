网络安全教学演示 · 客户端伪造数据上报 · 浏览器 → 教学代理 → 授权 mock 服务器

使用须知： 本页演示如何把"原本只能在 Python requests 里跑的伪造请求"通过教学代理在浏览器中复现，目的是讲解 Mixed Content / CORS / gzip / MD5 鉴权 / 轨迹时间戳篡改。 请只把 authUrl / summaryUrl / uploadUrl 指向你自己授权、自己控制的教学 mock。 指向真实生产系统提交伪造数据违反学术诚信和大多数地方法律法规，本课程材料明确不为此提供帮助。

配置导入

尚未导入配置。粘贴你的 JSON 或选择文件。

登录鉴权（form-urlencoded + MD5）

默认密码 = passwordPrefix + 学号，再做 MD5。代理把组装好的 name=[...] form 体 POST 到 authUrl。

查询跑步里程（gzip JSON）

代理把 {'studentno':...,'uid':...,'schoolno':...} gzip 后 POST 到 summaryUrl，返回累计里程和上次跑步时间。

上传跑步数据（gzip JSON + 轨迹时间戳重写）

代理读取轨迹文件，把每帧时间戳替换成 [begintime, begintime+usetime] 区间内的均匀时间，再 gzip 后 POST 到 uploadUrl。

批量上传（循环 N 天）

按"距今 N 天前"循环上传同一条轨迹。两次请求间会随机停顿，避免被同一时刻多笔上传识别。

这页是怎么"绕开"浏览器的

浏览器有两道墙挡着前端直接调 HTTP 接口：

  • Mixed Content：HTTPS 页面调 HTTP 资源 → 直接拦截。GitHub Pages 只能 HTTPS。
  • CORS：跨源请求需要服务端返回 Access-Control-Allow-Origin。教学 mock 不会下发这个头。

这页的破解办法 = 把 Python 的活搬到一台同时面向你授权 mock 和面向公网 HTTPS 的代理服务器上：

浏览器 (HTTPS) → cloudflared HTTPS 隧道 → FastAPI 代理 (HTTP, 内网)
              → 你授权的教学 mock (HTTP)

代理负责浏览器做不了的活：

  • 修改 User-Agent 模拟 Dalvik/okhttp 客户端
  • 把请求体 gzip 压缩
  • 对密码做 MD5（其实 SubtleCrypto 也能做）
  • 按运动时长重写每一帧的 GPS 时间戳
  • 透传响应给前端 + 同时把"组装出来的明文 body"发给前端展示，方便你给学生讲

反作弊视角看哪些位置可以识别

  • 每帧时间戳间距 = usetime / framecount → 均匀到不真实，扎堆 30Hz / 25Hz 的整数倍
  • 轨迹本身是固定的几条预录的"宿舍 → 一教"路径，UID 不同但轨迹完全相同
  • UID 来自一个固定列表，会出现"5 个学生的设备指纹一样"的模式
  • 速度分布（min/km）跟人体生理上限对比，校园场景 12km/40min 偏快
  • 同一 IP 短时间内出现多个学号上传 → 代理本身就是个识别点
