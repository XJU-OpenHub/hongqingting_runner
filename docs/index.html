        说明 / FAQ
        
    
          
  • HTTPS 混合内容：GitHub Pages 是 HTTPS，浏览器会拒绝从 HTTPS 页面发到 HTTP 后端的请求。把后端做成 HTTPS（自签 + 证书安装，或用 Cloudflare Tunnel/Caddy 自动 HTTPS），或本地运行该页面（python -m http.server）。
    • 
          
  • CORS：后端要返回 Access-Control-Allow-Origin: https://<your>.github.io（或 *），处理 OPTIONS 预检，并允许 Content-Type 头。
    • 
          
  • User-Agent：浏览器禁止 JS 修改 UA。原 Python 脚本里设置的 okhttp/... / Dalvik/... 在浏览器里都不会生效——发出去的就是浏览器自己的 UA。如果你的服务器要根据 UA 鉴别，需要放宽规则或改在后端测。
    • 
          
  • Content-Encoding: gzip：当前脚本和原 Python 一样，body 是 gzip 字节，但不显式声明 Content-Encoding，由服务器按惯例自行判断。
