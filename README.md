## 本地环境（可选）

如果想直接跑 Python 脚本：

```bash
# 1) 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate          # Windows: .\.venv\Scripts\Activate.ps1

# 2) 装依赖
python -m pip install -r requirements.txt

# 3) 运行
python hongqingting.py
```
